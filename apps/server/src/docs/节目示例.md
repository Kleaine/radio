## DJ 写稿要点回顾

从上面积累出的规律：

1. **开幕词要落地**：不念"欢迎收听"，而是点出当前时间、天气、情绪
2. **介绍歌曲时说"你听"而不是"这首是"**：用听众的耳朵去描述，不是背书
3. **话术和歌是交替的**：不是"下面请听 A，下面请听 B"，而是说话→歌→说话（针对刚播完的歌）→下一首歌
4. **有知识但不卖弄**：录音年代、制作细节、圈子背景——自然带出来，不堆砌
5. **收尾自然**：不"谢谢收听"，一句轻松的总结就够了
