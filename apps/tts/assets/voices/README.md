# Voice Reference Audio

Put clean reference audio files here:

- `gentle_female.wav`
- `lively_female.wav`
- `announcer_male.wav`

Requirements:

- 5 to 15 seconds each.
- One speaker only.
- No background music or loud noise.
- The spoken text must match `prompt_text` in `configs/voices.json`.
- The current demo references use local Windows SAPI voices as placeholders. Replace them with real Chinese dataset clips before final presentation if time allows.
